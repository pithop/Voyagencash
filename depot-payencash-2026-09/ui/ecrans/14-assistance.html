Questions fréquentesToutes →
Où est mon code de paiement ?
Dans Réservations → Réservations en cours, et dans tes notifications. C'est la référence de ta commande : tu n'as rien à montrer à personne. Ce que tu saisis pour régler, c'est le code du Bon d’achat PayEnCash que tu as acheté chez un commerçant.
Où consulter mon billet d'avion ?
Dès l'encaissement : PNR + e-billet par SMS et email. Dans l'app : Réservations → Confirmées → Mon billet. C'est la compagnie qui gère ton enregistrement (le lien est dans le message).
Mon prix bloqué expire — que faire ?
Garanti 1 h, gratuitement. S'il expire : bouton « revalider le prix » — rien n'est perdu, le tarif du moment s'applique.
Comment annuler ou changer ma réservation ?
Ton tarif est écrit noir sur blanc avant l'achat (packs Flex / Super Flex). Va dans ta réservation → Annulation — un remboursement repart par le chemin d'où l'argent est venu : re-crédit de ton bon d’achat, avoir, ou virement sur un RIB à ton nom.
Faut-il une carte bancaire ou un RIB ?
Non, un bon d’achat suffit. Il n'y a pas de champ pour ça dans l'app, et aucun paiement ne bascule sur une carte, à aucun montant. Ce qui plafonne, c'est ton Bon d’achat PayEnCash — — par bon d’achat, — par jour — et le ticket anonyme, au-delà duquel un compte vérifié est demandé.
Où acheter mon code ?
Chez un commerçant près de chez toi : le réseau des Bons d’achat PayEnCash (des commerces sous contrat avec nous) — ou auprès d'un distributeur mobile qui vient jusqu'à toi. Tu repars avec un code, tu le saisis dans l'app, c'est réglé — garde le ticket, le code vaut titre.
